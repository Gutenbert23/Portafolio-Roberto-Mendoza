# Roberto Mendoza | Portafolio Fotográfico

One-page portfolio diseñada para fotografía profesional de alto calibre (retratos, eventos y productos). Construida exclusivamente con tecnologías web estándar (HTML5 semántico, CSS3 moderno y Vanilla JavaScript), optimizada para carga rápida, responsividad y hosting en **GitHub Pages**.

## 🚀 Características Principales

- **Arquitectura ligera**: Sin dependencias ni frameworks pesados (0 KB de librerías externas).
- **Diseño Dark Elegante**: Paleta de alto contraste enfocada en la exhibición visual de imágenes.
- **Navegación Fluida**: Menú fijo translúcido (*backdrop blur*), soporte *smooth scroll* y menú hamburguesa en móviles.
- **Galería Interactiva**: Sistema de filtrado por categorías mediante JavaScript ligero.
- **Formulario de Reserva**: Validación frontend nativa con retroalimentación en tiempo real.
- **Accesibilidad**: Uso de etiquetas semánticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<footer>`) y atributos ARIA.
